## Card Match (Matchy Matchy)

A card-matching memory game built from scratch in Unity.

### Features
- Smooth, non-blocking gameplay — flip and compare cards continuously without waiting on prior comparisons to resolve.
- Multiple grid layouts (2x2, 3x3, 5x6, and more), with cards auto-scaling to fit the display area.
- Save/load system for persisting progress between sessions.
- Scoring system with combo tracking.
- Sound effects for flipping, matching, mismatching, and game over.
